# Written survey (backup)

Use this only when a contact cannot meet. Say in the email that a call is still preferred. A returned form is a written response. It does not by itself satisfy the expectation of three to five discussions.

Ask the respondent to name their role and the type of site. Tell them not to include customer names or meter files.

1. What is your role? (energy manager / equipment supplier / project developer / researcher / other)
2. On industrial sites you know, what usually happens to solar power that exceeds the load at that moment? (used on site / exported / curtailed / do not know)
3. Is a battery used with that solar system? (yes / no / sometimes) If yes, what for?
4. How is the battery scheduled today? (manual / fixed timetable / vendor software / not scheduled / do not know)
5. Which constraint causes the most trouble? (power limit / state of charge / warranty or cycle limit / export limit / missing forecasts / other)
6. Which result should a scheduling tool improve first? (solar used on site / energy charge / demand peak / backup duration)
7. Would you look at a recommended schedule before it is sent to equipment? (yes / no / only if each interval is explained)
8. May we cite your role and organisation in the diploma? (yes / organisation only / no)

Record the reply in [interview-log.md](interview-log.md). Do not treat unanswered questions as agreement.
